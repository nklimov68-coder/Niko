# ¡Hola! — мини-приложение курса испанского

Адаптивный статический сайт на HTML, CSS и JavaScript. Работает на GitHub Pages без сборки и сервера. Все пути относительные: сайт поддерживает адрес вида `username.github.io/repository/`.

## Перед публикацией

1. В `config.js` укажите Telegram без `@` или email автора. Telegram имеет приоритет. При пустых контактах сайт честно сообщает, что заявка не отправлена, и позволяет скопировать сообщение.
2. При желании заполните `price` и `startDate`: они появятся под финальной кнопкой записи.
3. Согласуйте предложенную программу в `app.js` (массив `months`). Длительность — 3 месяца / 12 недель. Это редакционный черновик, а не подтверждённое описание вашего курса.
4. Отредактируйте `index.html`: название, описание, формат обучения, ответы на вопросы. Удалите пометку «Предварительная программа» после согласования.
5. При необходимости добавьте реальные условия оплаты, оферту и информацию об авторе. Цена, отзывы, квалификация и даты намеренно не выдуманы.

## GitHub Pages

Загрузите **содержимое этой папки**, включая скрытые `.github` и `.nojekyll`, в корень репозитория на ветке `main`.

В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `Deploy to GitHub Pages` запустится при push в `main`; также его можно запустить вручную на вкладке Actions. Если ветка называется иначе, измените `branches` в `.github/workflows/pages.yml`.

Альтернативно выберите **Deploy from a branch → main → /(root)**: сборка не нужна.

## Локальный запуск

Из папки проекта выполните `python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Для остановки нажмите Ctrl+C.

## Что работает

- Программа с тремя вкладками и управлением с клавиатуры.
- Мини-урок из трёх вопросов с пояснениями и результатом.
- Озвучка испанской фразы средствами браузера (зависит от доступных голосов).
- Вопросы и ответы.
- Диалог записи: подготовка сообщения, копирование, переход в Telegram или почтовую программу.
- Адаптивная мобильная версия и поддержка reduced motion.

Форма не хранит и не отправляет данные автоматически, платежи не принимает. Заявка отправляется посетителем в выбранном мессенджере или почте. При необходимости подключите собственный платёжный сервис внешней ссылкой.

Шрифты загружаются из Google Fonts; при отсутствии интернета используется системный шрифт. Иллюстрация и favicon — локальные SVG, без внешних изображений и библиотек.
